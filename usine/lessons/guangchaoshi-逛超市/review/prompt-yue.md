# 「逛超市」台词对抗审查·zh-HK

【任务性质】
对抗审查：你的任务是**找出错误**，不是确认无误。大模型有顺从性——问「对不对」多半会说对；所以这里只要发现，不要表扬，也不要「总体没问题」式的收尾。

【材料背景】
中文短视频教学课「逛超市」的台词定稿。场景：超市购物——找牛奶 → 问价 → 要便宜替代 → 确认刷卡付款 → 塑料袋收尾。角色：A＝提议/提问方，B＝熟悉这家店的接题方，两人是同龄好友。台词行数应为 17 行，若你数出的不是 17 行，请将此异常列为第一条发现。价格均为教学虚构价，价格数字的合理性不在审查范围。手势与舞台指示已在摘录时移除，不用管画面呈现。

【审查维度】逐行检查：
1. 语法（一致关系、动词体、语序、助词等）
2. 拼写、用字、标点
3. 注音/罗马字与原文的逐词一致
4. 语体一致性（本课语体承诺见下）
5. 自然度：母语者在这个场景下会不会真的这么说（书面腔、直译腔都算发现）
6. 中文对照是否忠实传达原句意思（对照组不判文采）
7. ⚑ 教学注记里的语言说法与语法讲解是否正确（注记讲给中文观众，其中引用的外语例形同样要审）

【输出格式】每个发现一条：
行号｜原文片段｜问题（注明维度）｜修改建议｜置信度（高/中/低）
拿不准但可疑的也报，置信度标「低」并写明疑点。
整个语言若一行错都找不到，只写「未发现错误」四个字。
禁止输出确认性内容（「总体正确」「设计不错」等）。

【语体承诺】全程口语粤文（按口语音书写的通行粤语用字：喺/嘅/唔/咁/冇等），繁体字形。
【注音口径】括号内（*…*）是粤拼 jyutping（数字声调）；逐字核对声母、韵母、声调数字。
【对照口径】中文对照给的是普通话说法（粤语原意的普通话转述），不是逐字直译；审「普通话说法是否准确传达粤语原意」。

【台词】（行号在行首）
1. **A**（happy）：「阿晴，一齊去超市呀！」（*aa3 cing4, jat1 cai4 heoi3 ciu1 si1 aa3!*）——阿晴，一起去超市吧！
2. **B**（neutral）：「好啊，呢間我熟㗎！」（*hou2 aa3, nei1 gaan3 ngo5 suk6 gaa3!*）——好啊，这家店我熟！
3. **A**（happy）：「噉牛奶喺邊度呀？」（*gam2 ngau4 naai5 hai2 bin1 dou6 aa3?*）——那牛奶在哪儿？
4. **B**（neutral）：「牛奶喺凍櫃嗰邊，直行轉左。」（*ngau4 naai5 hai2 dung6 gwai3 go2 bin1, zik6 haang4 zyun2 zo2.*）——牛奶在冰柜那边，直走左转。
5. **A**（happy）：「呢樽幾多錢呀？」（*nei1 zun1 gei2 do1 cin2 aa3?*）——这一瓶多少钱？｜⚑粤语·超市：问价固定说「幾多錢」，别把普通话「多少钱」直接搬过去
6. **B**（neutral）：「十蚊一樽。」（*sap6 man1 jat1 zun1.*）——十块一瓶。｜⚑粤语·超市：「蚊」是钱的口语单位——十蚊＝十块，八蚊＝八块
7. **A**（happy）：「咁貴嘅？有冇平啲嘅？」（*gam3 gwai3 ge3? jau5 mou5 peng4 di1 ge3?*）——这么贵？有没有便宜点的？｜⚑粤语·超市：「平」就是便宜，「平啲」＝便宜一点；「咁貴」的「咁」＝这么
8. **B**（neutral）：「呢隻牌子平啲，八蚊。」（*nei1 zek3 paai4 zi2 peng4 di1, baat3 man1.*）——这个牌子便宜点，八块。
9. **A**（happy）：「好嘢！我要兩樽，得唔得？」（*hou2 je5! ngo5 jiu3 loeng5 zun1, dak1 m4 dak1?*）——好！我要两瓶，行不行？
10. **B**（neutral）：「得，自己攞啦！」（*dak1, zi6 gei2 lo2 laa1!*）——行，自己拿吧！
11. **A**（happy）：「可以碌卡嘛？」（*ho2 ji5 luk1 kaat1 maa3?*）——可以刷卡吗？
12. **B**（neutral）：「得，拍卡就得。」（*dak1, paak3 kaat1 zau6 dak1.*）——行，拍一下卡就行。｜⚑粤语·超市：「碌卡」＝刷卡，「拍卡」＝感应式拍一下——上一句问「可以碌卡嘛」，这句答「拍卡就得」，两个词正好对照
13. **A**（happy）：「膠袋要錢嘛？」（*gaau1 doi6 jiu3 cin2 maa3?*）——塑料袋要钱吗？
14. **B**（neutral）：「要呀，一蚊一個，碌埋佢吖！」（*jiu3 aa3, jat1 man1 jat1 go3, luk1 maai4 keoi5 aa1!*）——要的，一块一个，一起刷了吧！
15. **A**（happy）：「我識晒喇：牛奶喺邊度、幾多錢、點樣碌卡！」（*ngo5 sik1 saai3 laa3: ngau4 naai5 hai2 bin1 dou6, gei2 do1 cin2, dim2 joeng6 luk1 kaat1!*）——我全学会了：牛奶在哪、多少钱、怎么刷卡！
16. **B**（encouraging）：「得閒再一齊嚟行超市呀！」（*dak1 haan4 zoi3 jat1 cai4 lai4 haang4 ciu1 si1 aa3!*）——有空再一起逛超市呀！
17. **A**（happy）：「好呀，拜拜！」（*hou2 aa3, baai3 baai3!*）——好呀，拜拜！
