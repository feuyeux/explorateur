拓扑是对的

  • 严格星型。只有 cli 与 dsh-plugin 两个入口依赖产线包；七个产线包彼此零依赖，全部只依赖 @feuille/core。
  • core 内部零环。30 个模块（38 个源文件）的依赖边全部指向更低层，Tarjan 实测无强连通分量。
  • 路由表诚实。commands.ts 登记 39 条、leaves/ 实存 39 个文件，零孤儿零死登记，router 测试逐条验叶子真实可达。
  • 产线包很薄。publish 是 base+clock 星型，poster 只有 pixels 一处私有共享，karaoke/poetry/storyteller/bgm/copy 内部零依赖。
  • 铁律落进了依赖图。画字只经 platform 解析浏览器，成像库被 textlayer/covers 挡住不直接画字。

本轮已收敛的三处

  • ① 静态环归零。scenePaths / lessonsDirOf 从 skill 专属的 parse_scene 下沉到 library 的 data（顺带收敛了 lesson.ts 里重复的第二份实现）。data 的闭包从 errors, parse_scene 缩到只剩 errors——library 不再反向依赖 skill 层。
  • ② clamp 下沉 core.num。rig 的闭包从 imaging/pildraw, num, tts/index 缩到 imaging/pildraw, num，WebSocket 握手栈不再进人物 rig 的依赖闭包。tts/pure 保留转出以不打断外部调用方，口径本体仍唯一。
  • ③ 24 处死命令清零。面向用户的 uv run 全部指向已退役的 Python 入口——lesson doctor 的「下一步」提示正是它的核心契约，照着跑必然失败。
  • 金样本有据可查。为修 ③ 动了 migration/golden/scene_draft.md 一行——那是迁移 parity 证据，改了就可能自证。偏离点、理由、日期已写进 migration/README.md，不是静默改动。

入口面的取舍

  • cli 是耦合面最大处，且是有意的。513 LOC 里 15 处直调 core、另 25 处直调七个产线包——它是唯一同时触达 L1 与 L2 的节点，正是「统一入口」的定义。代价是新增产线必须改路由表。
  • dsh-plugin 是 CLI 的能力超集。673 LOC 覆盖 18 个 usine_* 工具，带 approval 红线 fail-closed 与 publish 默认不注册。红线在智能体面是可执行的，不只是注释。
  • 两入口有覆盖差：poster 的十条与 publish 的合集/回列表核验在插件面收敛成单个工具，粒度比 CLI 粗。要行为完全等价，得为每个叶子各写一份工具 spec。

文档与实测的两处小差

  • 工具数：docs/architecture.md §4 写「17 工具面」，实测定义 18 个 usine_*。自洽解释是 usine_publish 默认不注册（17 + 1 gated），但正文没写这句，读者会以为对不上。
  • 归属描述：ownership.json 写 publish「对包内其他模块零依赖，自成一体」，实测 publish 内部是 base+clock 的星型（7 个模块依赖它俩）。措辞会被读成「publish 内部零依赖」，与代码不符。
