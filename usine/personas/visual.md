## 1. 用色：高质量

> 原 `plan.md` §7.2


1. **token 化**：色值只存在于 `personas.json` 与主题文件；lint 禁止组件/模板出现 hex 字面量。
2. **可读性**：语种标识色上的文字对比度 ≥ 4.5:1（WCAG AA）；描边 `#4B4B4B`、1080 画布线宽 6px、圆角与三条缓动曲线全班底统一（character-animation.md 一致性节）。
3. **可辨性**：标识色承担"语种一眼认"，但永远与国旗 emoji＋语种文字**双通道冗余**（沿用 tts_page.py 状态栏既有设计）；示范九语横排相邻者避开同色系邻对。
4. **无刻板分配**：配色由性格与标识色决定，不做"粉色=女生"；文化元素几何化、低细节（[plan.md §3](../docs/plan.md) 原则四）。

## 2. 动作：高质量

> 原 `plan.md` §7.3


1. **弹性物理**：`bounce` 采用余弦平滑缓冲曲线（`1 - cos` 连续阻尼），跳跃（`mini_jump` / `jump_celebrate`）采用单次蓄力-起跳抛物线-落地缓冲三段式光滑插值，彻底消除尖锐 V 形抽搐与一蹦一蹦撞地感；视线微漂移平滑自然，去除阶跃抖动。
2. **确定性 idle**：眨眼/呼吸/微晃全部帧函数（`random(seed)` 错相、0.4Hz 正弦呼吸），同帧同貌（character-animation.md 确定性 idle 一节）。
3. **口型同轴**：口型与逐词高亮字幕共用 `captions.json`（路线 B 三态口型：闭/开/宽），说话联动传导到眉与身体（`browLift`/`bodyScale`）。
4. **挂件物理**：项链/挂绳/围巾 swing、帽子 bounce、镜片 reflect——四锚点分层渲染，遮挡层级进 rig 常量。
5. **片内动作零重复**（2026-10-03 用户反馈定型）：同一人一支片内的手势按出场次序在
   「签名码 → 槽位语义池 → 全能量池」轮换（§4 moves 注、`resolve_pose_seq`），全片已用码跳过、
   不得相邻重复；同台 A/B 词汇表互斥再加固一层。验收口径：全语种逐人手势序列去重后
   长度不减（qa 逐语种断言，当前 14 语种全过）。
6. **遮嘴类图层事故零容忍**（承手册坑⑮）：人物绘制内图层序固定为
   背发 → 腿脚 → 躯干/挂件 → 手臂 → 颈与头 → 前发 → 胡子 → 表情 → 头部配饰；
   任何新增姿态/服饰先过「嘴部窗口异物色 = 0 像素」抽帧探针再入册。

## 3. 人物绘制规格（多邻国式头身，单一事实源 `intro_cards.face_geo()`）

> 原 `plan.md` §8.3


单位 = 头高 H。脸型规格表 `FACE_SPECS`（头身高谐调收敛在 356~378px，头身比例统一协调；
heart＝上圆下贝塞尔圆收下巴（禁尖角——尖下巴观感像鬼）、square＝方颌（$m=2.40$ 超椭圆优美颌线），下颌轮廓由
`draw_character` 组合绘制，其余型为纯椭圆）：

| 脸型 | 头高 H | 头宽系数 WH/H | 观感 | 分配示例 |
|---|---|---|---|---|
| round | 356 | 0.955 | 活泼婴儿圆宽脸 | Miles/Chloé/Felix/Anya/Eleni/Omar/Haruka/Doyun/Noa/阿晴 |
| tall | 378 | 0.810 | 清瘦修长（收敛过长下巴） | Théo/Mateo/Nikos/Riku/Luca/阿豪 |
| oval | 372 | 0.860 | 端庄鹅蛋脸（柔和匀称） | Ruby/Lena/Lucía/Layla/Seoyeon |
| wide | 356 | 0.980 | 宽和大脸（自然协调） | Misha/Yuval |
| heart | 368 | 0.900 | 心形俏丽脸（柔顺收下巴） | 小满/Priya/Giulia |
| square | 374 | 0.880 | 英挺方颌（优美下颌角轮廓） | 江远/Arjun |

渲染与 qa 探针都从 `face_geo()` 取派生几何，永不漂移。**躯干与肩同宽、臂嵌进躯干轮廓、
肩楔填平头-肩缺口**（剪影连续是硬要求，杜绝"头身手脱节/手像悬挂"——
见 render-handbook.md §5 坑⑪）：

| 部位 | 比例 | 说明 |
|---|---|---|
| 头占身高 | ~46% | 大头短身，头身比例全班底协调（全班底 H 集中在 356~378px） |
| 躯干宽 | 0.435×头宽 = 肩半宽 | **躯干与肩同宽**（宽高 0.52H）；肩楔三角衔接颈部两侧→肩峰 |
| 眼位 | 头顶下 0.615H | 明眸灵动；瞳距 ±0.30×头宽；巩膜 0.272×0.312×头宽；瞳孔占巩膜 ~75%（带虹膜下光与双高光） |
| 眉位 | 巩膜顶上方 0.030H（brow_y = eye_y − 0.170×头宽 − 0.030H） | 匀称微弧眉（线宽 0.020H，自然微弧紧贴眼上） |
| 嘴位 | 头顶下 0.815H | 张嘴开口联动；闭口为优美微笑微弧（宽 0.088×头宽） |
| 腮红 | 头顶下 0.680H | 活泼型自然苹果肌腮红（眼正下方 ±0.30×头宽，椭圆 0.065×0.038H） |
| 四肢 | 上臂 0.27H / 前臂 0.24H / 臂宽 0.155H / 手径 0.21H | 胶囊袖 + 袖口收边；**肩关节内收至躯干轮廓上**（`sh_hw − arm_w·0.30`），静止角 7° |
| 腿脚 | 腿宽 0.185H、腿距 ±0.145H；脚长 0.335H、外八字 +0.085H | 圆角鞋形 + 鞋头高光 |

画质工艺：**全链路 2x 超采样**（人物层、场景层、气泡尾、进度条按 2x 语义坐标绘制，
BOX 精确降采样 = 全形状抗锯齿）；无描边纯平涂 + 双色发丝高光 + 耳朵/衣领/侧体积影细节。
名牌/语言牌/气泡：药丸形 + 身份色/墨色描边 + 半透明投影（matte 双色抠像精确还原投影 alpha）。
