# 选词门：母语用量校验（2026-11-03 加）

**起因**：ep01 寿司期韩语格教了 스시（日语借词），粉丝指出日常更通用的是 **초밥**（醋饭）。
스시 不是错词，但不是「去韩国张嘴点菜最稳的那个」。根因是选词跟着「和日语/英语对仗」走，
没跟着「当地人实际说什么」走。本门把粉丝那次的验证方法（母语词典 + 搜索结果量对比）固化成流程。

**时机**：每期数据定稿前、任何词条改动前，**在配音与渲染之前**做完——改词在数据阶段是零成本，
成片后是重渲成本。

## 三步

1. **母语词典过一遍**：每个词在目标语言的母语词典里能查到词条级条目（不是「只在词典里存在」的
   冷僻形）。常用词典对照：
   | 语种 | 词典 |
   |---|---|
   | ko | Naver 국어사전 |
   | ja | 大辞林（Weblio） |
   | de | Duden |
   | fr | Larousse / Le Robert |
   | es | RAE |
   | ru | Грамота.ру |
   | ar | Almaany |
   | he | Morfix |
   | hi | Shabdkosh |
   | 其余 | 对应母语权威词典；查不到权威源时在日志里写清用了什么 |
2. **竞争说法比用量**：借词与本土词并存时（스시/초밥 这类），把候选都列出来，用目标语言的
   搜索结果量或语料库对比，**常用的进画面，另一个做备注**（评论区、发布词或补充内容），
   不许只教自己先想到的那个。
3. **场景判据**：入选标准是「在餐厅/超市张嘴就说的那个词」，不是「和日语/英语对仗的那个词」。
   拿不准的宁可不写（与 README「三条纪律」第 1 条同一口径）。

## 粉丝纠错的标准动作

1. 先独立核实（词典＋用量），不直接认错也不硬杠——借词与本土词往往**都对**，差在通用度。
2. 核实成立 → 改数据 → 在 `check_ep01_regression.mjs` 的 `REVISED` 登记（仅 ep01 需要）→
   重渲后删条目。
3. 评论区置顶「补充两者区别」而不是逐个辩解；把提供证据的评论者变成校对员。
4. 内容价值够的就出一条补充短内容，把勘误变成新选题。
