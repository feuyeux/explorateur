# 每集注音/转写核对清单（模板）

每集开画前出一张：**4 词 × 12 语 = 48 行**，用户逐行过审才进构建。为什么逐集
出而不全系铺一张大表：480 格转写一次铺完审不过来，错音烙进画面只能整集重做。

语种序 = `one-page-poster` §Conventions 的规范序（12 语种集合与顺序的唯一
事实源，不在这里抄第二遍）。着色方式按 script 分派（sc/latin/cyrillic/greek/
deva/ar/he/jp/kr），与 `tools/foodnames` 的口径一致。

```markdown
### 第 NN 集 · <中文标题>（<EN 标题>）

| # | 语种 | 词形 | 注音/转写 | 着色方式 | 备注 |
|---|---|---|---|---|---|
| 1 | 汉语 | 苹果 | ㄆㄧㄥˊ ㄍㄨㄛˇ | sc 逐字注音 | |
| 2 | 英语 | apple | ˈæp.əl | latin 元音红/辅音蓝 | |
| … | | | | | |

**中央主体画面**（本集 4 张插画的主体描述，外观特征，不写水果名）：
- apple: …
**旁白句式**（每语一句，画面句 == 配音句，过 `check_sentence_matches` 口径）：
```

## 填写规则

- **词典基本形**：名词取单数（英语 grape 不收 grapes；日语引く辞書形口径同）。
- 注音体系固定：汉语**注音符号（ㄅㄆㄇㄈ）不用拼音**；日文 Hepburn；韩文
  文化观光部 2000 罗马字；印地 ISO 15919；阿文 DIN 31635；希文 ISO 259。
  不得为配色改拼写。
- 语言称谓一律本地名（English / Deutsch / 日本語…），禁统一「×语」标签。
- 有地区变体的格（`fruitlist.json` 的 `variants`）：默认词形进主列，另一形
  写进备注并注明地区（例：西语 grapefruit 默认 toronja，备注 pomelo（España））。
- 拿不准的转写**当场标记「待母语者核」**，不许静默放行。
