## 这个样例真正想留下的三件事

1. **顺序**：先发作品再建合集。抖音合集创建页**只列已发布作品**，作品没发时面板是空的。
2. **判据**：脚本自报和退出码都不算证据，**唯一权威判据是回管理列表核验到这条作品**。
   草稿箱计数不是判据——编辑过程中就自动存草稿，计数与成功没有对应关系。
3. **如实报告**：B站合集是**账号 Lv2 门槛**，不是配置问题；等级不够时编辑页的
   「加入合集」是灰字、无任何可点控件。此时不要绕、不要硬闯，如实说只裸投稿。

## 换主题时最容易踩的一处

**封面序号是全局连续的**：成片是 `竖版四季_俄语.mp4`（无序号、用中文语种名），
封面是 `13_竖版_中文.png`（有序号）——横版 01–12、竖版 13–24，**不是每个版式各自
从 01 重开**。猜成 locale（`ru-RU`）或按版式重排，全批 24 条都会被 `build_manifest`
拦下。**先 `ls` 看真实命名，再写映射。**
