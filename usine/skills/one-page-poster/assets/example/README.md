# 工作样例：「一杯茶」12 语种海报源（全验收）

这是 2026-10 复用验证项目 `one-cup-tea-poster` 的成套源文件，全流程验收通过（charset 全覆盖、12 格无溢出、印地/阿/希叠层 0.00% 失配、金色独占标题）。**模板 `assets/template/` 只有骨架；每种文字系的着色标记（12 个 worked cell）以本样例为准**——换主题时按语种逐格替换文字内容，标记结构照抄：

- `poster_src.html` — 12 个语种格子的完整标记：汉语 `.zi` 注音列、拉丁/西里尔/希腊逐字母 span、印地语 `.stack` 双层 + `.sp` 垫片（चाय：ा 在基字后）、阿/希 `dir="rtl"` 双层叠印（零步进符号从顶层删除）、日语 `.wjp` 音注列 + `.cv` 合体假名、韩语 `.ksyl` 背景色块
- `fonts.json` — 与上面对应的字体子集清单（OBS SC/JP/KR/Arabic/Hebrew/Deva/West 七族）

**注意：韩语色块几何是逐字形实测值，不是常数**——`ks2/kta/kja` 只对 한/차/잔 成立。换任何谚文音节都必须用 `scripts/measure_korean.py` 重新测量（该脚本就是从本项目提炼的），不要照抄样例里的百分数。同理，天城文 `.sp` 的 0.2691em 是 Noto Sans Devanagari 的 ा 实测步进，换字体族需复核。
