# 比分牌映射的实测坑表

全部数字来自 `usine/examples/derby-2026/`（485.48s 意甲官方 extended highlights，
比赛 95 分钟）。换比赛 / 换联赛时**方法照抄、数字重测**。

## 1. 映射表怎么建

- 全片 `fps=1` 采样（485s 母版 = 485 帧 png）；
- 转播比分牌位置整场固定，裁出时钟/比分区竖拼成长图逐帧读 MM:SS 与比分。
  derby 实测裁窗：`crop=100:36:170:86`（时钟列）与 `crop=60:36:400:86`
  （比分列）。**先抽 3–5 帧探针定裁窗再批量裁**——每个联赛转播包的比分牌
  几何不同，抄别的联赛的坐标必裁空（derby 项目里的 `probe/` 与 `sheets/`
  就是这一步的产物：`probe/score*.png` 定位、`sheets/f*.jpg` 逐帧存档）；
- ffmpeg 场景检测 `select='gt(scene,0.25)'` 的切点聚集与比分牌读数互相印证
  （derby 的 `scene-detect.txt` / `score-cuts.txt`）。

## 2. 集锦的时间轴不是匀速的

95 分钟压进 485s，名义压缩比 ≈ 11.7×，**逐段 10×–20× 还不等**——回放段
压缩比是负的（时间倒流），庆祝段几乎原速。任何「按比例换算比赛分钟 → 视频
秒」的写法都错，窗口落点只能来自比分牌读数 + 场景切点。

## 3. 跳切：被跳过的事件放在跳切上讲

官方集锦会整段跳时间。derby 实测两刀：

- 视频 311→314s：比赛时钟 69:46 → 73:26；
- 视频 353→354s：比赛时钟 74:56 → 89:58。

72 分钟国米换人、81–89 分钟双方换人都发生在被跳过的时间里——**画面里根本
没有换人镜头**。这两段换人解说就放在跳切点上，旁白说的时刻与画面跳掉的
时间一致；不要去找不存在的换人画面，也不要把解说落在跳切前（观众看到的
还是 69 分钟的画面，听到 72 分钟换人会错位）。

窗口表里这两段记 `kind: 'jump'`、`visible: 'absent'`：旁白只报进程与战术影响，用「这两分钟里」开头，不写任何动作细节（换人镜头不存在）。写法见 [visual-commentary.md](visual-commentary.md) §4.2。

## 4. 进球包是三段结构

一个进球在集锦里通常 = 现场画面 → 比分牌动画 → 慢放回放，三段各占一个窗口。
derby 第 4 分钟进球实测：现场 36–42s、比分动画 ~42s、回放 43–57s。写词时
分开处理：现场段讲过程，回放段讲细节（跑位 / 脚法），不要两段说同一句话。
场景检测里进球包表现为 0.5+ 的切分聚集（42.68 / 56.32 两处 score 0.53–0.62）。

三段在窗口表里各占一个窗（`kind` 分别 `live` / `graphic` / `replay`），信息职责分开：现场讲过程、比分动画讲数据与意义、回放讲细节。一窗里既现场又回放，旁白必然有一半对不上画面。

## 5. VAR 图形页是可读锚点

VAR 段有整屏图形页（derby 336–345s，页面写 PAVLOVIC / FOUL）——把页面上
**实际出现的名字与判罚词**当锚点写进事实，不要从旁白或比分倒推是谁的手球。
改判结果（点球 → 角球）以官方比赛页事件表为准。

## 6. 终场哨的判定

终场哨 = 场景切点聚集 + 比分牌最后一次可读（derby：403–406s，最后读数
95:03）。之后的画面是握手 / 绕场 / 看台，写「赛后」窗口。片尾如果整段变黑
或出字幕，场景分会出现 1.000000（derby 472.44 / 475.44 两帧）——那是片尾
不是事件，别把它当终场哨。

## 7. 换了工作区/母版，旧映射一律作废

比分牌几何、压缩比、跳切位置都是**这一条母版**的属性。凡是换过母版、
换过裁窗，旧映射表不许复用，重走第 1 节。探针脚本（裁窗定位、逐帧存档）
在 derby 的 `probe/` 流程里，不搬数字。

## 8. 渲染中断的 mp4 不是产物

成片渲染十几分钟，被杀（会话结束 / 断电 / 手动停）就留下没有 moov atom 的
文件——`ffprobe` 报 `Invalid data found`，**不管文件看起来多大**（derby
实测 288 MB 的废片）。判定口径只有 ffprobe 能过；重跑前先删废片。
教训：成片渲染跑后台，跑完第一件事 `ffprobe` 验时长，再谈别的验收。
