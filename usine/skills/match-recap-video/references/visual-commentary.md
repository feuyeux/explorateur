# 画面解说：把「比赛进程」与「眼前画面」写成一句话

本文件是 SKILL.md「两条轴：进程轴 × 画面轴」的具体做法。数字取自 2026-10-25 米兰德比实跑（485.48s 意甲官方 extended highlights 母版；项目产物按落位规则在 `usine/examples/` 下、不入库，可能已清理——数字已固化在本文件与 `assets/fixtures/windows.good.json`），**文字都是写法示意，不是逐字稿**；换比赛 / 换联赛时方法照抄、画面重读、数字重测。

## 1. 三种错位：为什么照官方页念不行

- **声音超前**：球还在半空，旁白已经喊「进了」。观众被剧透，画面失去张力，而且一旦没进就是硬错。
- **声音滞后（回放误判）**：画面已经切到慢镜，旁白还在按现场讲「第 4 分钟」。回放是**时间倒流**，进程词落在回放上会被听成「又进了一个」。
- **声音错位（跳切编画面）**：画面从 69:46 跳到 73:26，旁白说「他跑向边线」。被跳过的时间里根本没有这个镜头——解说在描述不存在的画面。

三种错位的共同根因：只有一个时间轴（比赛时钟），没有第二个「画面状态」轴。只看进程轴会编画面，只看画面轴会丢进程，所以窗口表必须两轴并存。

## 2. 读画面五步（写词之前做完）

1. **切窗**：窗口边界落在场景切点上，**一窗一个镜头状态**。同一镜头内从传球到进球可以留在一个窗；一旦换机位、进慢放、出图形页，就必须切窗。边界记进 `t0 / t1`，精确到 0.1s。
2. **抽帧并看四栏**：每窗取头 / 中 / 尾三帧（`t0 + 0.2s`、中点、`t1 − 0.2s`）；窗口短于 1.5s 取中帧一帧即可并在 `see` 里注明。抽帧用 `ffmpeg -ss <t> -i <master> -frames:v 1`，不要用整段导出再找。四栏是：景别与机位（远景 / 中景 / 特写；主机位 / 门后 / 边线）、主体（号码 / 位置 / 动作）、可读的屏幕信息（比分牌 MM:SS、比分、图形页文字、字幕条）、是否回放（慢放 / 换机位 / 回放角标）。
3. **写 `see`**：一句话写「画面上看见了什么」，只写看得见的，不写推断。号码不可读就写「（号码不可读）」，不要拿名单猜。`see` 是**证据**，`say` 是**解说**——两者不是同一句话。
4. **判 `visible`**：`event`（动作本身可见）/ `aftermath`（只见结果：庆祝、比分牌动画、球员表情）/ `absent`（事件发生在被跳过的时间里）/ `unread`（画面没读）。`absent` 的窗只能写进程，不能写动作；`unread` 是**运行环境没有视觉输入**时的显式降级（模型不能读图、视觉代理不可用），`see` 只写 OCR 能自证的比分牌/图形页，`check_windows.py` 对动作对账降 WARN，交给人眼或视觉复核。
5. **存档**：抽帧放 `shots/w{NN}-{a,b,c}.jpg`，另记一份 `shots/index.tsv`（`key, kind, visible, t0, t1, see, 帧路径`）。验收时逐行对账，不靠回忆。

### 2.1 没有视觉输入时怎么办（`visible: unread`）

实跑会遇到两种断法：当前模型不支持图像输入，或视觉代理的供应商不可用。这时不能假装读过画面——**编出来的 `see` 比没有 `see` 更糟**。可行的降级是：

1. 用 `read_scoreboard.py` 对比分牌做 OCR，拿到逐帧分钟/比分；用场景切点定窗口；
2. `see` 只写 OCR 读数（「比分牌 OCR：60'，1-1（t≈96s）」），不写动作；
3. `visible` 一律标 `unread`，`say` 只写进程轴（时间/比分/谁/意义），不写「起脚」「扑救」「转身」这类画面动作；
4. `check_windows.py` 会对 `unread` 窗的动作对账降 WARN——**PASS 带 WARN 不等于画面已验收**，冻结前仍需人眼或视觉复核。

这不是「完成了画面轴」，是**把缺口显式标出来**。成片可以先出（进程轴 + 字幕 + 混音都成立），但 README / 发布前必须写明「画面读数 unread」。

## 3. 一句三拍

| 拍 | 回答什么 | 写法要点 |
|---|---|---|
| 定位拍 | 时间 / 比分 / 谁 | 3–8 字，只给观众「现在在哪」需要的最小信息 |
| 画面拍 | 这一窗画面上看得见的动作与关系 | 动词先行；只写 `see` 里有的主体与动作 |
| 落点拍 | 结果与意义 | 比分 / 助攻 / 赛季背景；数字在 `say` 里只出现一次（复述交给 `stat` 卡） |

**拍数预算**：4s 以上最多三拍，2–4s 两拍，≤2s 一拍（通常是画面拍）。三拍是上限不是必填——缺的那一拍由 `title` / `stat` 卡补上。阈值是起稿用的，**判据是 `build_voice` 每段实测的 slack**——超窗就压词或减拍，不硬塞。

**语体三则**：

- **动词先行、短句**：「右路起球到后点，普利西奇起跳，头球破门。」不要「这是一次由莫雷拉在右路送出的精准传中，普利西奇完成了头球攻门」。
- **现在时**：说「起球」「起跳」「扑到」，不说「完成了」「将会」。
- **专名首现给全名 + 位置**，之后可省姓；译名从 `配文.py` 的名单取，全文一致。

## 4. 六个典型场景

### 4.1 进球包：现场 → 比分动画 → 回放（三个窗）

| key | kind | visible | `see`（示意） | `say`（示意） |
|---|---|---|---|---|
| w05 | `live` | `event` | 右路起球到后点，普利西奇起跳压过后卫，头球入网（远景，门后机位） | 右路起球到后点，普利西奇压着后卫起跳，头球破门——德比客场先手。 |
| w06 | `graphic` | `aftermath` | 比分牌动画切到 1-0，屏幕下方进球条：PULISIC 4' | 1-0，普利西奇。 |
| w07 | `replay` | `event` | 慢镜另一侧机位：起脚前抬头观察，后点两名防守球员之间出现空当 | 再看一遍——起脚前那一下抬头，找的就是后点这个空当。 |

三段的信息职责不同：现场讲**过程**，比分动画讲**数据**，回放讲**慢镜才看得出的细节**。不要两段说同一句话。比分动画窗常常只有 1–2s（derby ~42s），只够一拍读数据——意义放进 `stat` 或下一窗的落点拍，不要硬塞。

### 4.2 换人：被跳过的时间（`jump` / `absent`）

derby 实测两刀：311→314s（69:46 → 73:26）、353→354s（74:56 → 89:58）。72 分钟与 81–89 分钟的换人都发生在被跳过的时间里，画面里没有换人镜头。

- `see` 写读数：「比分牌 69:46 → 73:26；画面直接切到 73 分钟界外球，无换人镜头」——**只写读数，不写动作词**（机检判据 3 对 `see` 与 `say` 都扫动作细节词，`see` 空也会给 WARN 提醒补读数）；
- `say` 只写进程与影响：「这两分钟里国米先动了棋子：72 分钟两人上、两人下，中场改成三中卫。」；
- **禁止**写「他跑向边线」「教练在场边叮嘱」——这些镜头不存在，写了就是编（`see` 里同样禁止）。

### 4.3 黄牌 / 红牌

- 只见裁判掏牌：`live`，说牌与对象，判罚依据以官方页为准；
- 只见球员围住裁判：`live`，说「围住裁判」这个可见动作，不替裁判解释判罚；
- 若是回放里的犯规动作：`replay`，只说慢镜里的接触部位，不报新的比赛分钟。

### 4.4 VAR：图形页是可读锚点

- `graphic` 窗读页面上**实际出现的名字与判罚词**（derby：336–345s，页面写 PAVLOVIC / FOUL）；
- `say` 先读页面再给结论：「VAR 介入，画面给到 PAVLOVIC 的手部动作——判的是犯规，不是手球。」；
- 改判结果（点球 → 角球）以官方比赛页事件表为准，不从旁白或比分倒推；
- 页面不显示动作本身时 `visible` 记 `absent`（或 `aftermath`），不要假装画面里看见了犯规过程。

### 4.5 扑救 / 中柱 / 单刀：画面事实

官方页没有这些条目，只能在 `live` / `replay` 窗里写，来源是**帧号 + 时间码**：

- `see`：「禁区外远射，门将侧扑指尖蹭到，球中柱弹出（中景）」；
- `say`：「这脚远射门将指尖蹭到，砸在立柱上——比分没变，但国米的气势起来了。」；
- 不加官方页没有的赛季数据（「本赛季第 N 次」）；号码不可读就用位置称呼（「国米左中卫」）。

### 4.6 阵容卡 / 终场 / 赛后

- **阵容卡**（开球前整段，derby 0–12s）：`kind: 'graphic'`，读卡片上可读的名字与阵型，与 `MILAN_XI / INTER_XI` 对账；
- **终场**：哨响与比分牌最后读数（derby 403–406s，最后读到 95:03）作为锚点，`kind: 'ambient'`，落点拍先行（比分、赛季意义），画面拍只写看台 / 握手 / 庆祝里真实发生的动作；
- **片尾黑场**不是事件（derby 472.44 / 475.44 两帧场景分 1.000000），不要当成终场哨。

## 5. 声画同步的机械细节

- **窗口 = 一个 TTS 段 = 一个镜头状态**。一句话不跨切点，否则后半句必然对不上画面。
- **LEAD 0.45s 保留**：画面先到位，声音再进来。回放窗的首句再晚一点进，先让观众认出「这是回放」。
- **首拍标记词**：回放窗用「再看一遍 / 慢镜里」，跳切窗用「这两分钟里 / 就在这段时间」，终场用「终场」。这几个词是给观众的时空路标，比精确到秒更重要。
- **结果词的落点**：「进了 / 1-0 / 扳平 / 反超」只允许出现在 `live` 的结果拍、`graphic` 的读页面拍、`ambient` 的落点拍；`replay` 与 `jump` 不允许出现新的结果。
- **回放可以引用本事件的时间**（「第 4 分钟那个球」），但不得引入新的比赛分钟或新事件。判据一句话：**这条信息是不是观众上一窗已经知道的？**（观众 = 听旁白 + 读字幕卡的人——`title` / `stat` 说过的就算知道。）
- **字幕卡与旁白不同时换**：卡片在窗口起点进，旁白按 LEAD 后进——观众先看画面，再听解释。

## 6. 验收与反向验证

### 6.1 逐窗对账表

每窗一行，人工勾：

| key | kind | visible | `see` 有主体？ | `say` 的动作都能指回 `see`？ | 回放 / 跳切是否推进了进程？ | 结论 |
|---|---|---|---|---|---|---|
| w05 | live | event | ✓ | ✓ | 不适用 | PASS |
| w07 | replay | event | ✓ | ✓ | 否（只讲细节） | PASS |
| w09 | jump | absent | 无动作 | 只有进程句 | 否（进程合法） | PASS |

### 6.2 三条硬判据

1. **动作可指认**：`say` 里每个动作短语，都能在同窗 `see` 找到主体与动作；找不到就改成进程句或删掉。
2. **回放不推进**：`replay` 窗没有新比分、新事件、新的比赛分钟。「观众还没听说过」的机检口径 = 前面各窗的 `say` **加 `title` / `stat` 卡**——卡片说过的，回放引用是合法的（§5：「第 4 分钟那个球」）。
3. **跳切不编画面**：`jump` 窗 `visible = absent`，`see` 只写读数、`say` 里没有动作细节（只有时间、人、战术影响）。

### 6.3 反向验证（纪律 2）

拿一份副本，故意注入坏例，判据必须全部抓到；抓不到就说明判据还只是注释。机检载体是 `scripts/check_windows.py selftest` 与 `assets/fixtures/windows.*.json`（好表 + 四个坏例，除注入点外逐字段一致）：

- **坏例 A**：把 `replay` 窗的 `say` 改成「第 72 分钟，国米换人」——应触发判据 2；
- **坏例 B**：把 `jump` 窗的 `say` 改成「他跑向边线，教练在场边叮嘱」——应触发判据 3；
- **坏例 C**：把 `live` 窗的 `say` 改成「后点起跳头球」，而 `see` 只有「禁区外远射」——应触发判据 1；
- **坏例 D**：把 `jump` 窗的 `see` 从读数改成带动作细节的描述（「跑向边线」「叮嘱」）——应触发判据 3（`see` 只准写读数）。

另有一层**输入契约**：空表、`kind` / `visible` 枚举笔误、区间倒挂一律退出码 2（输入坏了），不进判据、更不冒充 PASS——枚举写错会让判据 2/3 整段静默跳过，必须在门口拦下。

### 6.4 机检候选（只标记，不判决）

可以用词表扫候选：`\d+-\d+`、`第\s*\d+\s*分钟`、`又进|再进|扳平|反超`。命中只说明「这句需要人工看一眼」，**不能自动判 FAIL**——回放窗里「第 4 分钟那个球」是合法引用，语义判断不能机械化。

## 7. 翻车表

| 症状 | 根因 | 修法 |
|---|---|---|
| 「怎么又进了一个？」 | 回放窗推进了进程 | 回放只写细节，首拍加「再看一遍」 |
| 「换人镜头呢？」 | 跳切窗编了画面 | 改进程句，视觉锚点交给字幕卡 |
| 「这球谁进的？」 | 画面拍挤掉了定位拍 | 补 3–5 字定位，或把数据交给 `stat` |
| 「太满 / 太吵」 | 2s 窗塞了三拍 | 减拍，数据交给卡片 |
| 「在说谁？」 | 号码不可读却命名 | 改用位置称呼，不猜名字 |
| 「像念新闻」 | 长定语、书面语 | 动词先行、短句、现在时 |
| 「字幕和声音打架」 | `say` 复述了 `title` / `stat` | 遮住卡片只听旁白自检一次 |
