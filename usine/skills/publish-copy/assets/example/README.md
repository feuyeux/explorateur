# 《落叶》题眼文案成稿（活样例）

精修后的三平台发布词。出处：`karaoke-video` 示例《落叶》（12 语种三幕诗卡拉OK视频，竖屏 1080×1920 + 横屏 1920×1080）。示例项目随时可删——三份成稿按"题眼写法 + 字斟句酌"的标准入库留档。

**题眼**：一片叶子，落在十二种语言里。离枝、随风、归根——各自写。写到"归根"那一幕，写的全是"回家"——英语 Homecoming，德语 Heimkehr，俄语 Домой，希腊语借了荷马史诗"归途"那个词——Νόστος。英语"乡愁"（nostalgia）的根，就在这里。

**与 `../template/` 的差别**：template 是"one book"骨架（抄结构），这组是质量线（抄方法）。前者第一段铺规格，后者第一段抛题眼；**前者工艺散在正文、塞进"看片指南"段；后者工艺完全不进文案**——只承载思想/意境/态度；前者互动钩是"评论区点单"四个字，后者给到字面话术。最大的差别在**声音**——template 还能听到"营销体"（"小心机""睡前循环""藏了多少语言大佬"），example 把这些全部砍掉，每个动词都是自己挑的。三份稿同一条脊柱、三种嗓门：小红书情绪流、抖音钩子、B 站看完后想说的那一句。

**三道硬门**：模板与成稿都按 publish-playbook 坑 ① 在最后一个 `#tag` 后留一个尾随空格（Slate 联想面板线上事故的解法）；三份文件均通过 `scripts/check_publish_copy.py` 的机检门（标题字数 / 尾随空格 / 互动钩 / 置顶话术 / no-hard-wrap，0 违规）；成品自检三问与"读一遍有没有 AI 味 + 读完后读者带走的是感受还是规格单"的人工走查均过。

## 改动对照（template 骨架 → example 成稿）

| 维度 | template 骨架 | example 成稿 | 为什么 |
|---|---|---|---|
| 第一段 | "一条视频集齐了 12 种语言" | "一片叶子，落在十二种语言里" | 第一行要让人停下滑动的手——列规格不卖货，抛画面卖 |
| 题眼 | 无 | "落叶归根。根不只埋进泥土" | 一句话脊柱，三份稿共用；不破不立 |
| 工艺细节 | 散落正文 / 退居"看片指南"段 | **全部不进文案** | 文案要给读者思想/意境/态度，不是解释画面；工艺留给 README 与技术文档 |
| 思想/态度 | 无 | "不是翻译，是各自写。念完这十二种语言，会觉得落叶是活的" | 文案给读者的是**感受**——不是「字幕怎么动」的技术说明书 |
| 引文 | 笼统的"12 种文字" | "叶子飞着，像一封信" + 俄语原文 | 必逐字取自事实源 `配文.py`；模糊指代不卖货 |
| 序号引用 | 无 | "第 7 个希腊语"（对过时间轴） | 位置引用必须对成片时间轴核过再写 |
| 互动钩 | 模糊的"评论区点单" | 具体话术（"我先来：会 3 种…"） | 模糊钩子读者不会接；给字面才能复制 |
| 话题尾随空格 | 缺（已修） | 缺（已修） | publish-playbook 坑 ① 线上事故；缺则 Slate 联想面板改内容 |
| 投流备选 | 无 | `## 备选文案（投流版）` | 抖音给"另一种开法"，跟主稿不一样，AB 看数据 |
| 跨平台脊柱 | 各说各的 | 12 语 → 归根 → 回家 | 同一条脊柱换嗓门 = 同一支片的三种讲法；不要三稿各挖一个钩 |
| 文学调性 | 偏营销/钩子 | 字斟句酌、人文气息 | AI 味是行业病——template 里"小心机""睡前循环"是典型签名；example 把每个动词都改过 |

把这一栏对着 `template/*.md` 与 `example/*.md` 各开两份窗口比着读——同一套骨架，"规格单文案"和"题眼文案"的差距在每一行都在。
