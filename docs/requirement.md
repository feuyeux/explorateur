# 界面与人物设定设计规格文档

## 1. 界面布局设计（Layout Specification）

界面整体采用分层分区的结构设计：底部或主体展示角色，上方配合信息展示与状态气泡。   

```
+-------------------------------------------------------------+
|                                                             |
|                          文字区                             |
|              (系统对话 / 剧情文本 / 引导字幕)               |
|                                                             |
+------------------------------+------------------------------+
|                              |                              |
|          气泡区: 提示        |         气泡区: 思考         |
|      (快捷引导 / 操作提醒)   |      (角色心声 / 运算状态)   |
|                              |                              |
+------------------------------+------------------------------+
|                                                             |
|                                                             |
|                           人物区                            |
|             (Live2D / 3D模型 / 角色动态立绘)                |
|                                                             |
+-------------------------------------------------------------+
```

### 1.1 区域功能说明

- **文字区**：位于信息显示主视区，用于承载对话台词、主剧情叙述或系统引导文字。   
- **气泡区**：   
  - **思考气泡**：展现角色的心理活动、内心独白或正在处理/加载的状态反馈。   
  - **提示气泡**：提供交互反馈、上下文指令或玩法/操作指引。   
- **人物区**：占据画面的关键视觉重心，用于呈现角色的外观、动作、表情和挂件搭配。   

## 2. 人物设定体系（Character Specification）

```
                  ┌── 声音：语种、音色、语气
                  │
                  ├── 动量/动作：眼睛、嘴、肢体
人物设定 ─────────┤
                  ├── 色彩：头发、肤色、(乞丐/特色)服装
                  │
                  └── 挂件：头盔、项链、墨镜
```

## 3. 人物详细参数模块

### 3.1 声音表现（Audio Profile）

- **语种**：支持角色设定的母语及辅助配音语言（如普通话、方言或外语）。   
- **音色**：定义音域区间与特质（如低沉、少年音、沙哑、机械感等）。   
- **语气**：预设不同情绪分支下的语调风格（如慵懒、急促、调侃、坚定）。   

### 3.2 动态表现（Movement & Rigging）

- **眼睛**：眨眼频率、视线跟随（目光追踪镜头/光标）、眼神变化（微闭、睁大、凝视）。   
- **嘴部**：口型与语音音素同步（Lip-sync）、张嘴闭嘴与嘴角微表情（微笑、撇嘴）。   
- **肢体**：待机呼吸律动、受击/互动反应、专属待机动作（摆手、挠头、耸肩）。   

### 3.3 色彩配置（Color Palette）

- **头发**：发色基调、高光色彩与渐变方案。   
- **肤色**：基色调（冷白、暖黄、古铜色等）及光影边缘色。   
- **服装（乞丐/特色服装）**：主色调、做旧处理、补丁/破损细节质感配色。   

### 3.4 挂件与装扮（Accessories）

- **头盔**：头部配饰资产，定义遮挡层级与反光质感。   
- **项链**：颈部饰品，具备轻微的物理摆动与碰撞效果。   
- **墨镜**：面部挂饰，定义镜片透光度及高光反射效果。
