## 0. 一句话结论

既有六个系列里阿语是**散点**（B 系列一条场景支、E 系列一张 iḍāfa 图、F 系列一句回取），
没有一条**从字母到句子成体系的入门路径**——而这正是教材的结构。
本系列把两本教材的教学顺序直接翻译成 24 话视频序列，
并且**把选题全部压在 T0／T1 层级**，只有最后一篇场景对话落到 T2，
从而绕开母语者付费门禁（详见 §6）。

## 1. 教材总结

### 1.1 《新编标准阿拉伯语入门》（马超·谢伟）

一本面向零基础、以口语交际为目标的入门书。作者马超为北外阿语语言文学硕士，
曾赴阿尔及利亚公派留学、笔译一级。208 页，2021 年 12 月，中国纺织出版社。

**结构是六段递进**，与宣传页的「发音 → 词法 → 句法 → 单句 → 会话」完全一致：

| 部分 | 内容 | 对应话数 |
|---|---|---|
| 基础篇一 | 字母发音：字母概况 / 13 个发音符号 / 28 个辅音 | 01–06 |
| 基础篇二 | 日常词汇：名词 / 形容词 / 动词 / 虚词 | 07–12 |
| 基础篇三 | 常用句子：15 类交际功能（打招呼→初次见面→感谢→谦让→道歉→原谅→请求→拒绝→赞扬→批评→宽慰→悲观→喜悦→肯定→否定） | 19–21 |
| 基础篇四 | 日常对话：15 个场景（餐厅/问路/购物/问时间/打电话/理发店/图书馆/邮局/医院/银行/宾馆/机场…） | 22–24 |
| 提升篇五 | 词法：名词 / 动词 | 07–18 |
| 提升篇六 | 句法：句子分类 / 名词句 / 动词句 / 四种特殊宾语句 / 疑问句 / 感叹句 / 强调语 / 区分语 / 除外语 / 各类状语 / 动词句时态 | 13–18 |

**三个教学取向**决定了它适合被搬进视频：

1. **交际功能分类而非语法分类**。「表达谦让」「表达宽慰」这类分法是中国人编的，
   不是任何传统语法书的分法——**每一个功能名都是一条中文长尾搜索词**。
2. **口型图 + 文化风情解说**。发音部分依赖图像，这正好是视频的强项。
3. **结合艾宾浩斯记忆曲线设复习建议**——提示了复习型内容的存在缺口（可作后续扩展选题）。

### 1.2 北外《阿拉伯语基础语法》四册（外研社）

余章荣主编的《基础语法》编写组编写，1987 年初版、1999 再版、2010 新版，
国内高校阿语专业基础阶段权威教材。全书分**词法**（动词／名词／虚词）与**句法**两大部分，
「基本上保留传统阿拉伯语法书体系，又参考汉语、英语等现代语法书编排方法，
把复杂语法现象归纳为图表」。

| 册 | 部分 | 章节骨架（已核目录） |
|---|---|---|
| 第一册 | 词法·动词 | 词的分类 → 动词的时式（过去/现在/命令）→ 简式与复式 → 刚性/柔性 → 动词变化 → 动词词尾变化 → 及物/不及物 → 被动语态 → 残缺动词 → 变化/无变化动词 → 及两物心意动词 → 能愿动词 → 两种固定形式的感叹动词 → 褒贬动词 → 动名词 → 强调的 ن |
| 第二册 | 词法·名词 | 名词的种类 → 词尾三型 → 名词的性 → 数的名词 → 名词的格 → 指确指泛与冠词 → 根词 → 主动/张大/半主动/被动名词 → 比较名词 → 时空名词 → 工具名词 → 指小名词 → 从属名词 → **偏正合组** → 减尾/缺尾/延尾名词 → 代词 → 词数 → 柔母互换与字母变换 |
| 第三册 | 词法·虚词 | 虚词种类 → 介词 → 连词 → 疑问与应答虚词 → 类似虚词 / 类似动词的虚词 → 否定全类的 → 要求虚词 → 词根性虚词 → 呼唤虚词 → 强调虚词 → 提醒/附加/另起新句/详述/希望虚词 |
| 第四册 | 句法 | 句子种类 → 句子成分 → 名词句（起语/谓语/语序/多谓语）→ 动词句（主语/代主语/宾语/语序）→ **四种特殊宾语句** → 疑问句 → 感叹句 → 带结句的复合句 → 定语 → 强调语 → 同位语 → 解释性并列语 → 区分语 → 除外语 → 时空/原因目的/程度/状态/偕同状语 → **句子的时态** → 标点符号 → 术语阿汉对照表 |

**两个「编者创新章节」是选题金矿**：

- **《能愿动词》**（第一册）——传统阿语语法书不单列这一章。
- **《句子的时态》**（第四册）——阿语的**名词句也有时态**，靠 كان／إنّ 类虚词做杠杆。

编者特意新增这两章，说明它们是**中国人学阿语的公认痛点**。
视频就该打这两个点，而不是照着传统语法目录平铺。

**另一条信息：语法书把「偏正合组」独立成章**，这是 iḍāfa。
E 系列第 01 期已经锁了它；本系列把 iḍāfa 放在「词汇篇」而非独立系列，
是因为**对零基础观众，先讲「之」字比先讲偏正理论更有用**。

### 1.3 两套教材的互补关系

| 维度 | 《新编标准阿拉伯语入门》 | 北外《基础语法》四册 |
|---|---|---|
| 编排轴 | **交际功能 + 场景**（横切） | **词类 + 结构**（纵切） |
| 起点 | 发音与日常词 | 词法（动词先行） |
| 读者假设 | 能开口、敢开口 | 能扛术语、要查证 |
| 视频可采的部分 | 篇目即合集、15 功能 = 关键词簇 | 图表 = poster、章节 = 话数 |

**结论：两套不是二选一，是同一条路径的前后两段。**
本系列 = 入门书的**发音→词汇→功能**打底 + 语法书的**词法→句法**加深。

## 2. 从教材里挖出的六个选题灵感

教材本身只是目录。真正决定这个系列能不能跑起来的，是从教材结构里读出的**六个可产品化的钩子**：

### 灵感一 · 教材分篇即分集骨架

《新编》的六部分天然就是六个合集，《基础语法》的四册天然就是四个阶段。
**不为凑合集而设合集——直接用教材的分篇当合集结构**，
好处是内容有骨架、观众有进度感、后续出第二季不用重新规划。

### 灵感二 · 「日常不写元音」是全系列最强钩子

阿拉伯文是 abjad 文字：只写辅音骨架，短元音靠可选的附标（حَرَكات）标注，
而**日常书写的阿语根本不写这些符号**——读者靠词形与句法还原。

这是一个**反常识 + 有具体后果**的点：符号会不会写，直接决定你能不能读出正确发音。
kb 里已明确记载这一层是模型训练数据最稀薄、最易静默出错的地方
（`languages/arabic/grammar.md`「文字与读音接口」一节）。
**教学必须加注，加注又最易出错**——这个张力本身就是内容。

⚑ 注记：教材口径是「13 个发音符号」。**这 13 个的逐项枚举必须照抄教材该页**，
不要由模型自行生成——枚举型断言属词典级，需要外部权威对照。

### 灵感三 · 词根—模板是「一张图胜万言」的独家素材

阿拉伯语是非串联形态的教科书样本：词不是前后缀拼出来的，
而是**三辅音词根 × 模式模板「铸造」**的。掌握 = 词根表 + 模式表 + 不规则词。

这解释了一件学习者自己也说不清的事：**为什么记住三个字母就能顶几十个词。**
一张 K-T-B 词族图（كَتَبَ / كَاتِب / كِتَاب / مَكْتَب / مَكْتُوب / كِتَابَة / مَكْتَبَة / تَكَاتُب）
既是知识密度峰值，也是收藏率最高的内容形态——而「阿拉伯语语法」全网仅 2 条且均为广告。

### 灵感四 · 「字母四张脸」是天然的视觉钩子

每个字母有独立／首／中／尾四种字形（`kb/.../writing/alphabets/arabic-alphabet.md` 有完整对照表）。
字母 ا ب ت 只有 1 个点、letter ه 只有 2 个点，但**每个字母都要认四张脸**。

这比「来背 28 个字母」有效得多，而且**完美适配 poster 形态**：
一张图 28 组 × 4 形，本身就是可收藏的对照表。

### 灵感五 · 教材的「交际功能表」就是搜索词表

「表达谦让」「表达宽慰」「表达批评」——这三个词组在任何阿语教材的目录里都常见，
但**在任何中文平台的搜索结果里几乎没人做**。它们是现成的长尾词，
且与既有 §7.2-5 的修正结论一致：**标题一律前置语种名 + 具体场景词，概念词只留合集名**。

### 灵感六 · 编辑的「反传统」位置就是痛点位置

《基础语法》新增《能愿动词》《句子的时态》两章，第四册把**四种特殊宾语句**、
**名词句的起语/谓语**独立成章。这些都是传统语法书不单列的。
**编者判断「这里是中国学习者的坎」——比我们自己猜准。**

## 4. 单话脚本骨架

每话 45–60s，四段固定结构。**结构统一是刻意的**——写手只需填内容，
且账号纪律要求「每条正文措辞各异、结构雷同会被判异常」，故**结构固定、措辞与场景必须逐话不同**。

| 段 | 时长 | 内容 | 例（第 04 话） |
|---|---|---|---|
| 钩子 | 0–5s | 一个反常识断言，制造认知缺口 | 「阿拉伯语的太阳，不读 al-shams」 |
| 立论 | 5–20s | 一句话讲清原理，给最小知识点 | 定冠词 ال 遇上「太阳字母」，lām 被同化掉 |
| 拆解 | 20–45s | 2–3 组例句，逐词高亮 + 转写 + 中文 | اَلشَّمْسُ（aš-šams）vs اَلقَمَرُ（al-qamar） |
| 收束 | 45–55s | 一句话总结 + 引导下一话 | 「月亮的 lām 留下了——明天讲哪套」 |

**画面规则**：
- 阿语一律 RTL 整行容器（`dir="rtl"`），不逐字 hack
- 罗马转写用学术转写，斜体括号，**永不发音**
- 中文解析跟在原文右侧（RTL 下的视觉左），不与原文重叠
- 逐词高亮用 `karaoke-video`，durationBudget 按阿语实测放宽

**声音**：
- Windows 本地无阿语音色时走 Edge `ar-SA` Online Natural（Zariyah / Hamed Natural）
- `ar-001` 归一为 `ar-SA`
- **注意**：文本须先剔除 harakat 再交 TTS，否则动符可能被拼读
  （kb `tech/system-admin/speech-systems.md` §7 记「RTL 与省略动符」为 ar-SA 的已知坑）
- 反过来：**语法讲解环节的 harakat 必须保留**——那正是第 03 话要教的东西

## 5. 标题与封面

**标题公式**：`阿拉伯语<知识点钩子>` ——语种名前置，钩子具体化。
系列名与话数进**封面角标**和**合集**，不进标题（沿用 §7.2-5 修正）。

## 6. 质量门禁：本系列的核心设计

沿用 §8 的三级分层，但**本系列在选题阶段就做了一次风险规避**：

| 层级 | 内容 | 本系列占比 | 门禁 |
|---|---|---|---|
| **T0 引文级** | 已出版原文的引用 | 0 话 | 逐字符对照出处 |
| **T1 词级** | 单词、固定短语、语法形态框架 | **21 / 24 话** | 码位级核对 + 三模型对抗 + TTS→ASR 回环 |
| **T2 句级** | 自由生成的完整句子 | **3 / 24 话（22–24）** | ↑ 全部 + **母语者终审（硬门禁）** |

**这个分布是有意为之的**：
01–21 话全部落在 T1，团队可用 kb 素材 + Wiktionary 逐码位自证，
**不需要花母语者的钱就能发**。只有三话场景对话必须走付费终审。

**第 03 话（发音符号）是本系列的例外，须加一道硬校验**：
harakat 是模型最易静默出错、团队又最易读不出错的层
（iḍāfa 教训：ر 在 رصاص 一族的元音被写错 18 处，而门禁全部报「✓ 命中」，
因为**对照源就是那份被污染的词表本身**）。
→ **13 个发音符号的枚举必须照抄教材该页并注明页码**，禁止模型生成。

**硬门禁沿用既有结论**：门禁只能验「一致」，验不了「正确」；
门禁的真相不能来自被它校验的东西。

## 10. 三条不可越线的纪律

1. **不自造高风险例句**（§5.7）。本系列把 21 话压在 T1 就是为此；
   真要写自由整句，进 22–24 且必须过五步门禁。
2. **13 个发音符号照抄教材页，不生成**。这是本系列最可能出错的一处，
   也是母语者评论区最容易一击致命的一处。
3. **门禁的对照源不能来自被它校验的东西**。iḍāfa 教训的原文：
   18 处元音错误全库通过「一致性」检查，因为真相源就是那份被污染的词表。
   对照源只能是 Wiktionary 词条 + 已出版教材。
