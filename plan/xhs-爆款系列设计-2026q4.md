### 0.2 已验证的机制结论（直接吃，不重复验证）

1. **小红书是长尾分发**：搜索 + 话题页 + 合集 + 主页互相导流；单条爆不爆不影响整体涨粉。
2. **合集是强信号**；每门课第 01 支建合集，其余挂入。
3. **蓝海语种跑量**（抖音 colors 实测）：阿语 331 / 俄语 270 / 粤语 259 / 印地语 253——「有需求 + 供给稀缺」语种稳定强于大语种。
4. **dialogue 形态的价值 = 可截图、可对照、可收藏**——这条在小红书成立。
5. **系列编号标题公式有效**：`系列名｜第N话 语种：具体场景`（colors 靠它跑通；孤立知识点+临时话题那批全灭）。
6. **⚑ 注记带长尾搜索词**：小红书 OCR/ASR 会读画面文字，画面里要出现「语种名 + 场景词」。
7. **发布纪律**：一天最多 2–3 条、隔开时段、措辞各异（结构雷同的批量内容会被判异常）。
8. **分集称「第N话」**，不称「课/集」；只有单支时**不硬编号**（directions 的教训）。
9. 小样本期（单条 <数千播放）：完播率/跳出率是噪声，**只看支间相对排序**；账号级看涨粉与封面点击率。

## 2. 系列详情

### A. 一图十四语（图文对照系列）· P0

**一句话定位**：每期一个高共鸣词，十四种语言一页纸说清——可收藏的语种对照表。

**为什么能爆（机制依据）**
- dialogue 形态的「可截图、可对照、可收藏」已被验证是账号在小红书的立足点——但此前只能截视频帧；
  一页纸海报把这个价值做成**原生形态**。
- 图文笔记是小红书搜索长尾的主力形态；对照表类内容天然高收藏。
- 海报首图即封面：大字对照矩阵本身就是钩子，直接修复封面点击率。
- 14 语种在视频里要 45s+ 才能过一遍，在海报里**一屏全收**——这是图文对视频的决定性优势。

**形态与产线路径**
- `one-page-poster`：14 语种逐字着色排版（RTL 语种由产线 `dir` 参数处理）。
- 笔记结构：首图 = 大字钩子 + 语种色块矩阵；后续图 = 分语种特写卡（一图一语种：原文 + 注音 + 中文），
  首期先出首图 + 整版两张，特写卡视数据再加。
- 发布词走 `publish-copy` 体例：标题 ≤20 字、钩子开场 → `·` 分条 → 真提问；画面文字含「语种名+场景词」（OCR 可搜）。

**选题（首批 6 期）**：谢谢 / 对不起 / 我爱你 / 新年快乐 / 晚安 / 多少钱
（social6、intro6、love-words 等旧课程题材方向可参考，但语料按写作纪律六条重新创作：⚑ 注记先行、独立创作禁止互译。）

**标题公式与示例**（≤20 字，短钩子 + 单 emoji）
- 「谢谢」的十四种说法，一图收好🙏
- 十四语道歉指南，先存再说🕊️
- 新年快乐×14，拜年直接抄🧧
- 「多少钱」用十四语问，出国必备💰
- 晚安的十四种写法，含注音🌙

**合集**：「一图十四语」（第 01 期建，后续挂入）
**封面策略**：首图即封面，大字 ≤8 字（情境词）+ 14 色块；3:4 安全区内（y 240–1680）
**节奏**：每周一 / 三 / 五各 1 期，与视频错峰
**数据观察点**（5 期后复盘）：收藏率、封面点击率是否从 4% 回升；只看期间相对排序

### B. 五语开口说（蓝海语种视频课系列）· P0

**一句话定位**：一门生活场景一门课，四门蓝海语种 + 一个锚语种，每支 45–55 秒真人对话课。

**为什么能爆**
- 蓝海语种是账号已被实测验证的最大变量（阿/俄/粤/印地跑量，大语种 8 个 <50 播放）。
- 「系列名 + 编号 + 语种 + 具体场景」标题公式已被 colors 验证；第二批孤立知识点全灭是反面教材。
- 小红书搜索「俄语入门」「阿拉伯语学习」「印地语」是长期存在的刚需搜索词，供给稀缺。
- dialogue 形态 + 合集 + 对照表截图 = 已验证的小红书三件套，本系列是它的制度化延续。

**形态与产线路径**
- `lesson-scene`（17 行骨架课件 + ⚑ 注记）→ `karaoke-video`（逐词高亮 45–55s，durationBudget 按语种实测放宽）
  → `make_covers` → `publish-copy` → `multilingual-video-publishing`。
- 一门课 = 一个场景（具体到街角）：5 语种各一支，进同一合集。
- 班底照 casting 表：活泼者当 A（求知视角）、沉稳者当 B（向导视角）。

**语种阵容**：每门固定 4 蓝海 = 俄语 / 阿拉伯语 / 印地语 / 粤语；第 5 席锚语种在日语、韩语间轮换
（锚语种负责把大语种流量引到蓝海语种支上）。

**发序（§8 质量门禁修正）**：每门课先发团队可自检支——俄（01 支，建合集）→ 粤 → 锚；
阿语/印地语支属高风险 T2，过 §8.2 五步门禁（含母语者终审）后补挂合集。合集先建后补不受影响。

**首批门课（选题即场景）**：逛超市 / 点咖啡 / 机场打车 / 药店买药 / 砍价
**标题公式**：`五种语言<场景>｜第NN话 <语种>`（XHS 实测体例，场景钩子放正文首行）

**合集**：每门一个合集（如「五种语言逛超市全集」，≤20 字）
**封面策略**：统一规范见 §3.1；系列内每门课的 5 支共用版式、只换语种色条与编号
**节奏**：每门 5 支分 3 天发（每天 ≤2 支，间隔 ≥4h），门与门隔 2 天；每周约 1 门课
**数据观察点**：涨粉（核心）；5 语种支间相对排序——验证锚语种轮换是否成立

### C. 常连科说书（文学家评书系列）· P1

**一句话定位**：评书先生常连科，醒木一拍，一话一位外国作家——人设与差异化的护城河。

**为什么能爆**
- 「第一幕」594 抖音播放是全账号单支最佳——说书形态跑过一次，但只做了开头就没续。
- 语言教学赛道里没有评书竞品；说书人是**账号记忆点**，从「工具号」变「人号」正是涨粉的关键（metrics 判读：观看涨而涨粉不涨 = 被当工具查）。
- 作家故事 = 小红书「文学」「人物故事」长尾搜索，且素材现成：`kb/arts-and-humanities/literature/authors/` 51 位作家。
- 中文为主、外文金句点缀——**朗读门槛低于教学视频**，完播占优。

**形态与产线路径**
- `storyteller-video`：每话 2–3 幕（一幕一景一镜一转场 + 醒木），60–90s/话；
  作家金句用原语种朗读 + 逐词高亮（karaoke 时间轴机制复用），旁白 = 常连科（zh-CN-YunjianNeural，评书调校已在册）。
- 文案先成 scene 稿：作家小传 + 代表作典故 + 1–2 句原文金句；⚑ 注记先行，语言学断言只进注记。

**首批 5 话**（kb 素材齐全度优先）：芥川龙之介 / 陀思妥耶夫斯基 / 卡夫卡 / 契诃夫 / 欧·亨利
**标题公式**：`常连科说书｜<作家>：<钩子>`

- 常连科说书｜芥川与罗生门
- 常连科说书｜陀翁欠债的三十年
- 常连科说书｜卡夫卡的保险柜
- 常连科说书｜契诃夫的药房
- 常连科说书｜欧·亨利的表链

**合集**：「常连科说书」（单一大合集，人设优先于作家分集）
**封面策略**：说书人立绘 + 醒木 + 作家名大字；系列角标「第N话」
**节奏**：双周 1 话（成片成本高，宁缺毋滥）；**抖音同步发**（说书形态已被抖音验证，是两平台共用的形态）
**联动**：每话可扩写为知乎专栏长文（知乎 playbook 已有），文末互链小红书
**数据观察点**：完播、涨粉、主页访客（人设型内容的转化路径是主页）

### D. 节气十四语（实拍配文诗系列）· P1

**一句话定位**：跟着节气日历走，每个节气一支实拍配文诗，语种轮着念。

**为什么能爆**
- 节气 = 小红书强长尾话题（「霜降文案」「冬至」每年应季回潮），**日历自带发布节奏与时效钩子**——不靠推荐也有一口搜索流量。
- 24 支封顶的自然完结合集 = 收藏钩子（「集齐」心理）。
- 《四季》24 支成片 + 24 条小红书文案已产出（12 语种 × 横竖），**台账里没有它们——先核对是否已上线，未上线即本系列的第一批弹药**。
- `intro/xiaoman.mp4` 节气卡已验证过节气题材的制作路径。

**形态与产线路径**
- `video-generation`（H3 实拍母版，**逐次确认额度**）→ `multilingual-video-poetry`（配文 + 侧链混音）→ `bgm-bed`。
- 每支 20–60s：一个节气，2–3 语种各一句应季诗/谚语——中低风险语种独立创作（禁止互译）；
  高风险语种（阿/印地）只引已出版译本或词典级词条（§8.3），不自写句子。中文注记带节气搜索词。

**排期（现成资产优先）**
- 先把《四季》竖版 12 支按「一树四季」合集排进日历（当下秋季，秋/冬支优先）；
- 新制节气支从下一个节气日起：霜降 10-23 → 立冬 11-07 → 小雪 11-22 → 大雪 12-07 → **冬至 12-22（大流量节点）**。

**标题公式**：`今日<节气>｜<语种>这样说`

- 今日霜降｜俄语的初霜这样说
- 今日冬至，十四语里的白昼最短
- 立冬｜阿拉伯语的冬天不用冷字

**合集**：「节气十四语」
**封面策略**：用《四季》已验证的封面帧方案（秋季 11.9s 金黄逆光帧思路）——节气实拍画面 + 节气名大字
**节奏**：只在节气日发（天然不连发），每支顶掉当天一支 B 系列
**数据观察点**：收藏、涨粉（「等更新」型内容，看回访与关注）

### E. 语法一页纸（cheat-sheet 系列）· P2

**一句话定位**：每语种一个「最劝退的语法点」，一张图讲明白，配一支讲解视频。

**为什么能爆**
- 「X语语法」是 evergreen 搜索词；语法 cheat-sheet 是学习类内容的收藏之王。
- 阿语、希伯来等 RTL 语种的中文语法图解在全网供给极稀缺——蓝海中的蓝海。
- 阿语偏正结构（iḍāfa）的逐词着色讲解视频在旧项目已经探索过、渲染方案验证过，是现成起点。

**形态与产线路径**
- 首发图文：`one-page-poster` 出一页纸图解（语种标识色 + 逐字着色 + 阿语 RTL 整行容器方向）。
- 视频跟发（1–2 天后同合集）：`karaoke-video` 60–90s 逐词高亮讲解，班底声或常连科。
- 写作纪律：语法断言全部进 ⚑ 注记，词典级才可断言，不确定宁可不写。

**首批 5 期**：阿拉伯语名词短语（iḍāfa）/ 俄语六格 / 日语て形 / 韩语助词 은·는·이·가 / 德语可分动词
**标题公式**：`<语种><语法点>，一张图懂`

- 阿拉伯语名词短语，一张图懂
- 俄语六格，终于画明白了
- 韩语助词什么时候用는
- 日语て形，一张图串到底

**合集**：「语法一页纸」
**数据观察点**：收藏率、搜索来源占比（长尾型内容，冷启动慢是正常的，看 7 天累计）

### F. 听声辨语（互动系列）· P2

**一句话定位**：同一句话十四种语言连播，你听得出几种？——评论区的钩子。

**为什么能爆**
- 账号互动数 144 / 观看 3,965，互动是最短板；猜谜格式是评论率最稳定的形态。
- 14 语种 TTS 全在库、语料可从已完成课件回取——**半天一支，全系列成本最低**。
- 发布词体例本就以「真提问」收尾，本系列把提问做成内容本体。

**形态与产线路径**
- `karaoke-video` 45s：同一句（如「晚安」）14 语种连播逐词高亮，片尾定格「你听出了几种？」。
- 评论区运营：置顶评论放答案 + 引导晒分数（晒分数是二次互动）。

**首批 3 支**：晚安 / 谢谢 / 干杯
**标题公式**：`十四种<句子>，听出N种算你赢`

- 十四种晚安，听出8种算你赢
- 十四语说谢谢，你能听出几种
- 全世界怎么干杯？听声猜语种

**合集**：「听声辨语」
**数据观察点**：评论率（账号最弱指标的单点突破）、支均涨粉

## 3. 横向基建（六系列共用）

### 3.1 封面统一规范——修「封面点击率 -62%」

- 全部走 `make_covers.py` 的 xiaohongshu 变体：1080×1920，文字必须在 3:4 展示安全区（y 240–1680）。
- 统一版式三件套：**顶部系列角标**（系列名+第N话）· **中央大字 ≤8 字**（钩子词）· **底部语种色条**（14 语种标识色，personas 已配好）。
- 封面文字本身 = 搜索词：语种名 + 主题词必须以画面文字出现（OCR 可读）。
- 系列 A 的首图即封面（海报大字矩阵）；系列 D 用实拍帧 + 节气大字。

## 8. 质量控制：分级门禁（回应「阿语内容被评论区指根本不对」）

### 8.1 问题定性：为什么蓝海语种的内容必被抓错

1. **蓝海语种的搜索者里，母语者密度最高。** 供给稀缺的另一面：搜「阿拉伯语」刷到我们的，
   相当比例是阿语母语者/专业生（母语者天然会搜自己语言的内容），不是零基础学习者。
   他们对错误的敏感度远高于学习者——「根本不对」的评论大概率来自这里。
   这不是流量问题，是**内容形态与受众错配后必然发生的事**。
2. **教学加注恰好踩在最易出错的层。** 阿语日常书写不写元音符号（harakat），我们为教学**主动加注**——
   而这一层恰是模型训练数据最稀薄、最易**静默出错**的部分（母语者自己都不常写）。
   TTS 照着错的符号读，母语者听一耳朵就知道；图文海报则把拼写直接印在画面上。
3. **内部门禁为什么没拦住：iḍāfa 教训（2026-10-11 实录）。** 旧项目阿语课件词表里，
   ر 在 رصاص 一族的元音被写成 كَسْرَة（权威是 فَتْحَة），全库 18 处错误；
   而「拿词表校验课件」的门禁对这 18 处全部报「✓ 全部命中」——因为**门禁的对照源
   就是那份被污染的词表本身**。最后是拿 Wiktionary 词条（词头 + 古兰经引文）逐码位核对才暴露。
   **结论：门禁只能验「一致」，验不了「正确」；门禁的真相不能来自被它校验的东西。**
4. 所以质量控制不是「再多检查一遍」，而是**分级**：不同层级的内容配不同强度的门禁；
   团队自证不了的级别，要么把内容降到可自证的级别，要么买母语者的背书。

### 8.2 内容三级分层 + 语种风险分级

**内容层级**（先分层，再谈检查强度）：

| 层级 | 内容性质 | 典型场景 | 谁背书 | 团队可自证？ |
|---|---|---|---|---|
| **T0 引文级** | 已出版原文的引用 | C 系列金句、D 已出版译本、E 语法书例句 | 出版社/作者 | ✅ 逐字符对照出处即可 |
| **T1 词级** | 单词、固定短语、语法形态框架 | A 词卡、D 词典级词条、E 变格表 | 词典学共识（Wiktionary/权威词典） | ✅ 码位级核对可自证 |
| **T2 句级** | 自由生成的完整句子 | B 对话支、D 自写短句 | 只有母语者能最终背书 | ❌ 高风险语种不可 |

**语种风险分级**（判定标准：团队内是否有人能读懂校对，而非语种热度）：

- **低风险**：粤语（汉字部分用户可判读，口语音准取决于 TTS 质量）、中文注记。
- **中风险**：俄语（西里尔拼写验证可靠、Wiktionary 覆盖极好、跨模型共识强；日/韩同理）。
- **高风险**：阿拉伯语、印地语（后续若引入希伯来语、波斯语同此）——
  阿语的 harakat、印地语的 matra/连写都是模型易静默出错且团队无人能判读的层。

**高风险语种 T2 五步门禁**（缺一不放行，前四步在产线内、第五步在发布后）：

1. **权威源词级校验**：句子拆到词，逐词过 Wiktionary/权威词典**码位级**核对
   （iḍāfa 修复已验证的方法论；对照源必须是外部权威，绝不用自建词表当真相）。
2. **三模型对抗审查**：GPT / Gemini / MiniMax 三家独立审，指令是「**找出错误**」而不是「确认无误」
   ——LLM 有顺从性，问「对不对」多半会说对，问「哪里错」才会挑。任一模型报错即打回。
3. **TTS→ASR 注音回环**：原文 TTS 朗读 → ASR 听写 → 与注音/罗马字比对。
   只验「拼写与注音一致」，**不验语法正确**——此步诚实标注为辅助，不作放行依据。
4. **母语者终审（硬门禁）**：渠道按成本递增——闲鱼/淘宝搜「阿拉伯语母语校对/找错」
   （单支 17 行对话的台词量级，行情约 20–80 元/支，估算以试单实价为准）、
   italki 找教师做找错任务、小红书站内私信阿语母语创作者（供给真空 = 站内发母语内容的创作者本就会被搜到）。
   预算估算：B 一门课高风险 2 支 ≈ 40–160 元/门 + 复检；A 系列高风险词条可按 10 期打包批审。
   首月先阿语、印地语各试 1 人，跑通流程再谈月度打包顾问（月预算量级：两位数到低三位数）。
5. **评论区指正预案（发布后兜底）**：置顶评论开放勘误；24h 内响应——致谢 + 置顶勘误 + 修订版补图；
   **绝不删指正评论**。母语者指正是免费的外延终审，处理得当是信任资产（母语者愿意留言 = 权威性背书），
   处理不当（删评/嘴硬）才是公关事故。
