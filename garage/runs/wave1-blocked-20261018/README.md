# wave1-blocked-20261018 —— 为什么留在这里（不是可删的垃圾）

**一句话**：这一批是 2026-10-18 第一次 Phase-1 波次的**失败实录**，而失败原因是**鉴权坏了**（不是代码坏了）。它留下来的价值是「一次真跑长什么样」的原始形态，不是可复现的产物。

## 里面是什么

| 文件 | 是什么 |
|---|---|
| `401_count.txt` | 一个数字：**184** —— 这一轮里 401 出现的次数 |
| `events.jsonl` | 波次事件流（`PHASE1_WAVE_STARTED` / `PHASE1_BRANCH_EXCEPTION`），边跑边落盘 |
| `ep001..ep005.project.md` | 五个开工前的项目简报表（**这一轮的输入**，不是产物） |
| `run.log` | 88 KB 的完整运行日志 |

## 为什么失败

`events.jsonl` 里每一条 `PHASE1_BRANCH_EXCEPTION` 都是同一个形状：

```
"classification": "infra",
"error": "MiniMax-M3 transport failure HTTP 401: {'code': 401, ...}"
```

**184 次 401**，全部 `classification: infra`（基础设施类失败，不是智能体做错了什么）。上游答的是鉴权，不是能力。

## 为什么这是「留」而不是「删」

- **它是那批读数的凭证。** 如果有人问「你们第一次跑是不是根本跑不起来」，答案在这 8 个文件里，删了就只剩一句无凭据的口头结论。
- **它是「infra 分类」这条设计的活样本。** `classification: infra` 与「智能体没做到」是两回事，这个区别在真实事件流里看得到，比在任何文档里读到的都清楚。
- **它不属于「明确无用」。** 项目简报是**输入**，删掉它不会让任何门禁变绿，只会让这一轮的输入无法复原。

## 别拿它当什么用

- **别拿它当「基线读数」。** 里面没有任何评分——它连模型都没真正答上话。
- **别拿它当「引擎有缺陷」的证据。** 失败在鉴权层，引擎那侧没被考到。
- 想知道那之后怎么修好的、同一波次第二次跑成什么样：读 [`garage/README.md`](../../README.md) 的运行手册与 `garage/distribution-usine.md`。
