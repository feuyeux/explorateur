## 1. 文档语言元数据（BCP-47）

- `documents` 表新增 `language TEXT NOT NULL DEFAULT 'en-US'`；上传弹窗提供语言下拉，
  空值默认 `en-US`；格式校验只看形状（主子标签 2–3 字母，后续子标签 2–8
  字母数字），非法标签在**入库前**拒绝（`normalize_language`），错误信息中文。
- 存量库由 `db.rs` 的 `ensure_documents_language_column` 幂等迁移治愈（先查
  `PRAGMA table_info` 再 `ALTER TABLE`，缺列时回填 `en-US`），沿用启动自愈先例。
- 语言标签驱动三件事：TTS 选音、RTL 排版（`ar-*` / `he-*` 源栏段落加 `dir="rtl"`）、
  声线缺失提示。

## 2. 选音与发音运行时不变量（src/tts.js）

### voiceRank 权重全表

各平台把恶搞音、机器人音、低质音与真人音混在同一个声库里按字母序枚举，
枚举顺序不可信，因此一律**加权排序**：

| 信号 | 权重 | 原因 |
|---|---|---|
| macOS 恶搞音（`Bad News`/`Cellos`/`Albert`…，或 URI `com.apple.speech.synthesis.voice.*`） | `+100` | 音效，不是语音 |
| macOS Eloquence 机器人音（`Eddy`/`Flo`/`Grandma`…，法语另有 `Jacques`；URI 含 `eloquence`，URI 不透明时回退裸 persona 名） | `+80` | 按字母序排在真人音（Kyoko/Mónica/Thomas/Yuna）之前，不罚则劫持法/西/日/韩 |
| Windows SAPI5 `Desktop` 音 | `+1` | 旧引擎，劣于 OneCore |
| 联网音（`localService` 为假） | `+2` | 离线零延迟更稳 |
| 默认音（`default`） | `-1` | 系统推荐 |
| 高清/神经音（`enhanced\|premium\|natural\|neural\|siri`，**name 与 voiceURI 同查**——macOS 把音质层级藏在 URI） | `-3` | 音质最好 |
| macOS 磁盘层级 `compact` / `super-compact` | `+2` / `+4` | 磁盘省位档，音质差 |

**排序永不做过滤**——只有机器人音的语种照样出声（由
`frontend_contract.rs` 的 `tts_ranking_sorts_but_never_filters` 源级断言守卫）。

### 其余运行时不变量

1. **精确语区匹配 + 归一**：`pickVoice` 先取精确 locale（en-US 不得落到 en-GB），
   `normLang` 归一平台拼写（`yue-HK`→`zh-HK`、`ar-001`→`ar-SA`）；
2. **参数锁死**：每次 `SpeechSynthesisUtterance` 显式 `u.rate = 1.0`、`u.pitch = 1.0`，
   杜绝引擎复用上一次的语速/音调；
3. **Chromium 坑防御**：`CANCEL_SETTLE_MS = 60`（cancel 后延时再 speak，防同 tick
   吞音）；`KEEPALIVE_MS = 10000`（长句 `pause()/resume()` 心跳防僵死）；
   **播音钮即停止钮**（再次点击同一元素即停止）；
4. **免抢跑挂起**：声库未就绪时点击存入 `pendingSpeak`，250ms 轮询兜底（2.5s 后
   放行），严禁让默认英文 voice 跨语种乱读；
5. **声库缓存**：`localStorage('tts.voices.v2')` 缓存上次声库（含 `voiceURI`，首屏
   提示即能判层级）；`voiceschanged` 监听 + 轮询兜底；
6. **朗读前剥离 `*`**：强调标记残片永远不入音；
7. **无头回归钩子**：`window.__ttsTestHook`（应用自身永不设置）暴露
   `voiceRank`/`voiceTier`/`pickVoice` 供测试桩注入声库清单。

### UI 接线

- 双栏源文每句带悬停浮现的 **🔊** 小钮 → `TTS.speak(btn, sentence.original, doc.language)`；
- 语法透视镜的 **🔊 发音** 同走 tts.js（按文档语言发音，不再硬编码 `en-US`）；
- 声线缺失（`voiceStatus(lang).voice === null`）时 toast 给出系统声线安装指引
  （`VOICE_INSTALL_HINT`，macOS 辅助功能→朗读内容 / Windows 语音包）。

## 3. 转写分段规范（src-tauri/src/translit.rs）

### 通用原则

1. **保留作者的字母与音标体系**（`ʿ`/`ḥ`/`ṣ`/`ð` 或 `ħ`/`ʕ`、`yū` 或 `yu-u`），
   只加连字符，不改写；
2. 只在**转写与文字明显错位**时才修正内容：漏音（은행 写成 `haeng`）、漏双辅音
   （تتخلى 写成 `takhalla`）、残留 IPA 符号混进罗马字（`oˈneul`、`aʧime`）；
3. 词内连字、词间空格；所有音节块一律连字（含助词/格尾——`우체국이` →
   `u-che-gu-gi`，不用「词素连字符」区分粒子）；
4. 自检口径：**>6 字符且无连字符的拉丁 token** 不合格；单词节词与短词
   （`yeop`、`dost`、`ga`、`jā`、`māf`、`hai`）不罚。

### 检查器的适用范围

`（*...*）` 注音（reading-aid gloss）里出现**粘连拉丁 token**，且注音前 30 字符内
有谚文/假名/天城文/阿文/希伯来文，才判违规。英语语言名（`Japanese` 等）与
英语借词注音（`zebra crossing`）豁免；markdown 链接与 URL 先屏蔽再量。
命令 `check_transliterations` 为同步纯函数，无数据库、无 async，不触 block_on 陷阱。

### 逐语分段细则

**韩语（谚文）**：1 音节块 = 1 段，采用标准罗马字的**读音形**（含同化），
对着谚文逐块核对：

| 谚文 | 分段 | 说明 |
|---|---|---|
| 환영합니다 | hwan-nyeong-ham-ni-da | 基准例 |
| 실례합니다 | sil-lye-ham-ni-da | 陷阱：실 不是 `sim` |
| 우체국이 | u-che-gu-gi | 국이 [ɡuɡi] |
| 것입니다 | geo-sim-ni-da | ㅂ+ㄴ → mn 同化 |
| 있습니다 | i-sseum-ni-da | |
| 않았어요 | a-na-sseo-yo | 4 块 ↔ 4 读音节 |
| 근처에 편의점이 있어요 | geun-cheo-e pyeon-i-jeo-mi i-sseo-yo | 의 [ũi]→i |
| 왼쪽으로 | oen-jjok-eu-ro | 助词 으로 连字 |
| 가져갔셨어요 | ga-jyeo-ga-ssyeo-sseo-yo | 6 块 ↔ 6 段，保留原字母 |

陷阱：转写必须逐块对谚文核对——同化让「字面切块」与「读音形」不同时，以读音形
为准，但段数应与音节块数一致。

**日语（假名）**：1 拍 = 1 段：

| 假名 | 分段 | 规则 |
|---|---|---|
| こんにちは | ko-n-ni-chi-wa | ん 单列 `n` |
| すみません | su-mi-ma-sen | |
| まっすぐ | ma-s-su-gu | 促音 っ 并入下段双辅音 |
| 行って | i-tte | 同上 |
| 徒歩十分 | a-ru-i-te ju-p-pun | 拗音/长辅音并入前段 |
| ようこそ | yō-ko-so | 长音 1 段（macron 拼式） |
| 夕食を | yu-u-sho-ku wo | 长音 2 段（wāpuro 拼式，与源文件一致即可） |
| 交差点 | kō-sa-ten | |
| 銀行 | gi-n-kō | |

长音拼式**同一文件内保持一致**：macron 风格 `yū-bin-kyo-ku` 或双元音风格
`yu-u-sho-ku`，跟随既有源文件的写法。汉字词读音以正文假名注音为准
（`一月（いちがつ）` → `i-chi-ga-tsu`）。

**印地语（天城文）**：1 音节/akṣara = 1 段，**词尾 schwa 删除**（按读音不按字面）：

| 天城文 | 分段 | 说明 |
|---|---|---|
| स्वागत है | svā-gat hai | ग 的词尾 schwa 删除 |
| क्षमा | kṣa-mā | conjunct क्ष 一段 |
| कीजिए | kī-ji-e | |
| नमस्कार | na-ma-skā-ra | स्का conjunct 一段 |
| कहाँ | ka-hāṁ | |
| नहीं | na-hī̃ | chandrabindu 随元音 |
| दोस्त | dost | 单音节词不拆 |
| बाद | baad | 同上 |
| चौराहा | cau-rā-hā | |

英语借词直接给英文/音译自英语的按音节：`bas`、`stóp`、`sig-nal`（सिग्नल）、
`me-ṭro`（मेट्रो）、`zebra crossing`（不拆）。

**阿拉伯语**：1 音节 = 1 段；冠词同化与 tanwīn 原样保留：

| 阿文 | 分段 | 规则 |
|---|---|---|
| مرحبًا | mar-ḥa-ban | tanwīn -an 保留 |
| كبيرة/صغيرة 相对：تتخلى | ta-ta-khal-la | 双辅音必须体现（两个 tāʾ） |
| الساحة | as-sā-ḥa | 冠词 assimilation |
| المتحف | l-maṭ-ḥaf | 太阳字母省略 |
| الطريق | ṭ-ṭa-rīq | |
| شكرًا جزيلًا | shuk-ran ja-zī-lan | |

**希伯来语**：

| 希伯来 | 分段 |
|---|---|
| שלום | sha-lom |

### 不分段清单（保持词级）

- **IPA 音标**：带 ˈ 重音符或音素符号（`/meɪ̯n kal raːt/`、`/ˈʕafwan/`）；
- **字母对应文字**：俄语、希腊语（`Извините`↔`Izvinite`、`Συγγνώμη`↔`Signómi`
  逐字母可对；西里尔/希腊文字本就不在检查器的目标文字集内）；
- **拼音、粤拼**：本就逐音节空格/带声调数字（`huān yíng`、`ngo5 cin4 maan5`）；
- **英语语言名与借词**：`Japanese`、`zebra crossing`。
