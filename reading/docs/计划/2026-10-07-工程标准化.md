# 工程标准化改造

日期：2026-10-07
状态：已完成

把本工程与同工作区的 `funny`（哼唱识谱）统一到 Tauri 官方
`create-tauri-app` vanilla 模板结构，共用同一套构建入口与文档分层。

---

## 1. 改造前的差异

| 维度 | `ready`（改造前） | `funny`（改造前） |
| --- | --- | --- |
| 前端源码 | `frontend/`（`index.html` + `css/` + `js/`） | 仓库根级 `index.html` + `css/` + `js/` |
| `frontendDist` | `../frontend` | `src-tauri/www/`（构建产物副本） |
| 入口 | `cargo tauri` | `npm run tauri:dev` / `npm run build:tauri` |
| 测试 | `src-tauri/tests/` | 仓库根级 `test_*.mjs` |
| 文档 | `README.md` + `docs/使用指南.md` + `docs/superpowers/{specs,plans}/` | `README.md` + 根级 `USAGE.md` |
| `rust-version` | `1.77` | `1.77.2` |
| `[profile.release]` | 无 | LTO + `panic = "abort"` |
| `bundle` 元数据 | 无 | `copyright` / `category` / 描述齐全 |

## 2. 执行动作

### 前端源码迁移到 `src/`

| 改造前 | 改造后 |
| --- | --- |
| `frontend/index.html` | `src/index.html` |
| `frontend/js/app.js` | `src/main.js`（入口脚本改名，与模板一致） |
| `frontend/js/{api,dual_reader,inspector,settings,vocabulary}.js` | `src/` 同名文件 |
| `frontend/css/{main,components}.css` | `src/css/{main,components}.css` |

模块间全部是相对路径 `import`，无需改动任何 import 语句；
`index.html` 的资源引用由绝对路径 `/css/…`、`/js/app.js` 改为相对路径，
与 `funny` 一致。旧目录 `frontend/` 已删除。

### 配置

- `tauri.conf.json`：`frontendDist` 由 `../frontend` 改为 `../src`；
  `bundle` 补齐 `copyright` / `category` / `shortDescription` / `longDescription`，
  与 `funny` 对齐。本工程无前端构建步骤，故不设 `before*Command`。
- `Cargo.toml`：`rust-version` 由 `1.77` 提到 `1.77.2`；
  补上与 `funny` 一致的 `[profile.release]`（`codegen-units = 1` + `lto` +
  `opt-level = "s"` + `panic = "abort"` + `strip = true`）。
- `.gitignore`：重排为统一模板（`node_modules/`、`src-tauri/target/`、`.DS_Store`
  归入统一区块），保留本项目专有的图标精简项与 `legacy-backup/` 说明。

### 测试适配

`src-tauri/tests/frontend_contract.rs` 硬编码了 `../frontend/js` 与 `app.js`：

- `frontend_js_dir()` → `manifest_dir().join("../src")`
- 读取入口文件的用例由 `app.js` 改为 `main.js`

改动后 `cargo test` 仍覆盖「前端调用的 command 必须在 `generate_handler!` 中注册」
「toast 不得用 innerHTML 拼接」等契约，目录再次调整时会立刻失败而非静默失效。

### 文档

- `docs/superpowers/specs/` → `docs/设计/`
- `docs/superpowers/plans/` → `docs/计划/`
- `docs/superpowers/` 整个目录删除，两份文档顶部加「历史文档」提示，
  指向本文件并说明 `frontend/` → `src/` 的后续变化
- README 重写：命令表与 `funny` 同构，新增「与标准的差异」小节，
  架构树更新为 `src/` 布局，文档树补上「设计 / 计划」两层

## 4. 注意事项

- 本工程在标准化前有 **17 个文件未提交改动**（含全部 Rust 后端与测试）。
  本次改造只动了配置、文档、`frontend_contract.rs` 的路径常量，
  **未修改任何业务 Rust 逻辑**；建议尽快提交基线。
- `[profile.release]` 是新增的，下次 `cargo tauri build` 会走一次全量 LTO 编译，
  耗时明显长于此前，属预期。
